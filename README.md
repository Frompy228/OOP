# Лабораторные работы на C

Двусвязный список. Индексы элементов начинаются с 0.

- **Лаба 1:** решение `C++.slnx`, весь код в `C++/main.c`.
- **Лаба 2:** решение `Lab2/Lab2.slnx`. В `list.h` находятся структуры и объявления функций, в `list.c` — восемь операций списка, в `main.c` — меню и `PrintList`.

Откройте нужное решение в Visual Studio с установленными средствами разработки C/C++. Проекты настроены на C17 и набор инструментов v145.

Чтобы скачать работы на другой компьютер, клонируйте репозиторий. Для получения последующих изменений выполните `git pull` в папке репозитория, предварительно сохранив свои изменения в Git.
